## 🚀 How to Deploy on Netlify

### Option 1: Drag & Drop (Easiest & Fastest)
1. Log in to [Netlify](https://app.netlify.com/).
2. Go to **Sites** and drag the entire project folder (`Social Media Link Hub`) into the **"Want to deploy a new site without connecting to Git? Drag and drop your site folder here"** area.
3. Your site will be live worldwide in seconds!

### Option 2: Connect via GitHub
1. Push this repository to GitHub.
2. In Netlify, click **"Add new site"** -> **"Import an existing project"**.
3. Select your GitHub repository.
4. Netlify will automatically detect `netlify.toml` with publish directory set to `.`.
5. Click **Deploy Site**.
